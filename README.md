### 🇦🇫 KaarYab Afghanistan

A trilingual opportunity platform designed to help Afghan youth discover jobs, internships, scholarships, remote work, courses, and training opportunities.

**Built with:** Next.js • TypeScript • Supabase • PostgreSQL • Tailwind CSS

**Highlights:**

* 🌐 English, Dari, and Pashto support
* ↔️ Automatic RTL/LTR layout
* 🔐 Authentication and role-based access
* 🛠️ Admin verification system
* 🔎 Search and filtering
* 🗄️ Supabase database and Row Level Security
* 📱 Responsive design

[Live Demo](https://kaaryab-gules.vercel.app/) • [Repository](https://github.com/Fatima-Rahmani79/Kaaryab)
